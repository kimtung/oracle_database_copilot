Phase 0 — Core Milestones
1. oracle-mcp-server Foundation server.py
  • Khởi tạo máy chủ MCP chuẩn SDK 2.x giao tiếp qua giao thức stdio.
  • Kết nối Oracle 19c qua Thin Mode (thuần Python/Rust), không cần Oracle Instant Client.
  • Async Connection Pool (oracledb.AsyncConnectionPool) tối ưu hóa truy vấn đồng thời.
  • Bộ 6 tools nền tảng: get_database_info, get_top_sql, get_sql_statistics, get_active_sessions, get_blocking_sessions, get_tablespace_usage.
2. Security & Oracle Grants grants.sql
  • Nguyên tắc Least Privilege: Account db_copilot_readonly chỉ có quyền SELECT trên view hiệu năng.
  • Tuyệt đối không cấp quyền INSERT, UPDATE, DELETE, DROP hay EXECUTE.
  • Bộ lọc làm sạch (Sanitizer): Tự động xóa hoặc ẩn mật khẩu trước khi ghi nhật ký.
  • Audit Logging: Ghi vết JSON ra sys.stderr bảo vệ kênh dữ liệu JSON-RPC.
3. db-copilot Backend Foundation app.py
  • FastAPI Application Factory cấu hình quản lý vòng đời (lifespan).
  • Kết nối bất đồng bộ PostgreSQL qua SQLAlchemy 2.0 và driver asyncpg.
  • Health check API: GET /api/v1/health kiểm tra trạng thái CSDL.
  • Cấu hình mạnh mẽ qua Pydantic Settings đọc biến môi trường từ .env.
4. Database Schema & Migrations 001_initial_schema.py
  • Cấu hình Alembic async migrations tự động đồng bộ lược đồ bảng.
  • Khởi tạo 8 bảng cốt lõi: databases, snapshots, sql_metrics, sql_baselines, incidents, evidence_items, mcp_audit_logs, diagnoses.
  • Đầy đủ chỉ mục (Indexes) và khóa ngoại (Foreign Keys) tối ưu hóa truy vấn lịch sử.
5. Docker & CI/CD Pipeline docker-compose.yml
  • Dockerfile độc lập cho cả 2 dự án dựa trên python:3.12-slim.
  • Docker Compose khởi chạy sẵn PostgreSQL 16 và Backend API.
  • GitHub Actions CI workflow tự động kiểm tra cú pháp (Ruff) và chạy test suites.
6. Unit Tests Suite test_phase0_tools.py
  • 14 tests cho `oracle-mcp-server` (Kiểm thử 6 tools cơ sở, sanitizer, audit log).
  • 3 tests cho `db-copilot` (Health endpoint, lỗi mất kết nối DB, domain models).
  • Tất cả các test chạy không cần Database thật nhờ Mock Session & SQLite in-memory.

Danh Sách 8 Bảng Khởi Tạo Trong PostgreSQL (Alembic 001)
  • databases: Quản lý danh mục CSDL Oracle mục tiêu (Host, Port, Service Name, Version).
  • snapshots: Ảnh chụp trạng thái hệ thống theo chu kỳ (Active sessions, CPU, Health score).
  • sql_metrics: Thống kê hiệu năng chi tiết theo từng SQL_ID (Elapsed, CPU, Buffer gets, Disk reads).
  • sql_baselines: Đường chuẩn hiệu năng bình thường của SQL theo giờ trong ngày và ngày trong tuần.
  • incidents: Quản lý sự cố hiệu năng phát hiện được (Severity, Status, Category, Diagnosis).
  • evidence_items: Các bằng chứng kỹ thuật hỗ trợ cho sự cố.
  • mcp_audit_logs: Nhật ký kiểm toán mọi lượt gọi Tool tới Oracle MCP Server.
  • diagnoses: Kết quả chẩn đoán và đề xuất xử lý từ AI Engine.
Bộ Lệnh Cấp Quyền Oracle Tối Thiểu (docs/grants.sql)
CREATE USER db_copilot_readonly IDENTIFIED BY "ChangeMe_2026!";
GRANT CREATE SESSION TO db_copilot_readonly;

-- Chỉ cấp quyền đọc các V$ và DBA views cần thiết
GRANT SELECT ON V_$DATABASE TO db_copilot_readonly;
GRANT SELECT ON V_$INSTANCE TO db_copilot_readonly;
GRANT SELECT ON V_$SESSION TO db_copilot_readonly;
GRANT SELECT ON V_$SQLSTATS TO db_copilot_readonly;
GRANT SELECT ON DBA_TABLESPACES TO db_copilot_readonly;
GRANT SELECT ON DBA_DATA_FILES TO db_copilot_readonly;
GRANT SELECT ON DBA_FREE_SPACE TO db_copilot_readonly;
